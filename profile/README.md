## What We Work On

Ruten Studio is a compact engineering workspace focused on practical infrastructure and long-running projects.

- **Game server operations** - configuration, maintenance, and tooling for stable server environments.
- **Automation** - scripts and workflows that reduce manual work and keep important data backed up.
- **Documentation** - shared notes, setup guides, and project knowledge that make operations easier to repeat.

## How We Build

We prefer tools that are simple to run, easy to inspect, and boring in production. A good project here should be understandable from its README, safe to operate from the command line, and friendly to future maintenance.

## Repository Notes

Most work in this organization is project-specific. Public repositories and organization-level files live here when they are useful as shared defaults or as an overview of the studio.
